# Cat Morph 0.2.0 — Android

- [Télécharger l’APK ARM64](https://github.com/MrKawot/Cat/raw/refs/heads/main/downloads/CatMorph-arm64-v0.2.0-debug.apk) — téléphones Android récents.
- [Télécharger l’APK universel](https://github.com/MrKawot/Cat/raw/refs/heads/main/downloads/CatMorph-universel-v0.2.0-debug.apk) — ARM32, ARM64 et x86_64.

Android 7.0 minimum. Versions de débogage signées, contrôlées avec apksigner et zipalign. Pas de validation sur appareil réel. Même clé de débogage que la version précédente.

Si le lien direct échoue, ouvrez le fichier APK dans GitHub et utilisez « Download raw file ». Pour un dépôt privé, connectez-vous avec un compte ayant accès au dépôt.

Les SHA-256 sont dans `SHA256SUMS.txt`. Les APK sont conservés dans Git pour fournir un téléchargement depuis GitHub sans dépendre des liens de fichiers cloud. Pour les versions suivantes, préférer GitHub Releases afin de limiter l’historique binaire.
